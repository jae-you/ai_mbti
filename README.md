# 나한테 맞는 AI 에이전트는? — 위임 성향 연구

AI 에이전트에게 어디까지 맡기고 어디서부터 사람이 해야 하는지를 찾는 온라인 실험입니다.
참가자는 16개 상황을 판단하고(1단계), 그중 3가지를 에이전트가 실제로 처리한 결과를
두 가지 버전으로 비교합니다(2단계). 끝나면 위임 성향 유형이 나옵니다.

## 구성

```
index.html                 # 실험 앱 (정적 페이지, GitHub Pages로 배포)
apps-script/Code.gs        # 백엔드: 응답 저장 + 자극 생성/캐시
analysis/simulate_power.py # 가상 데이터로 분석 모형과 검정력 확인
```

## 1. 스프레드시트와 백엔드 만들기

1. 구글 스프레드시트를 새로 만든다.
2. **확장 프로그램 → Apps Script**를 열고 `apps-script/Code.gs` 내용을 붙여넣는다.
3. **프로젝트 설정 → 스크립트 속성**에 두 개를 추가한다.
   - `ANTHROPIC_API_KEY` : Anthropic 콘솔에서 발급한 키
   - `SHARED_TOKEN` : 아무 문자열 (예: `jy-2026-delegation`)
4. **배포 → 새 배포 → 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 후 나오는 `https://script.google.com/macros/s/..../exec` 주소를 복사한다.
5. 스프레드시트를 새로고침하면 상단에 **연구** 메뉴가 생긴다.
   **자극 미리 생성**을 한 번 눌러 32개 협상문(16 시나리오 × 2 요인)을 만들어 둔다.
   한 번 만들어두면 참가자는 기다리지 않고, 모두가 같은 자극을 본다.

## 2. 앱 설정하고 배포하기

`index.html` 상단 `CONFIG`를 채운다.

```js
const CONFIG = {
  endpoint: "https://script.google.com/macros/s/..../exec",
  token: "jy-2026-delegation",
  gameCount: 3,
  irbText: "연구책임자 유재연 · 문의 sandrine86@hanyang.ac.kr",
  shareUrl: "https://<아이디>.github.io/<저장소>/"   // 배포 주소
};
```

GitHub 저장소에 올리고 **Settings → Pages → Branch: main / root**로 배포한다.
모집 경로를 나눠 보려면 `?src=twitter` 처럼 붙이면 `src` 열에 기록된다.
패널을 쓸 경우 `?pid=...`로 참가자 식별자를 넘길 수 있다.

## 3. 데이터 보기

- `raw` 시트에 세션 JSON이 그대로 쌓인다 (단계가 끝날 때마다 1행, 중도 이탈도 남는다).
- **연구 → 분석용 시트로 정리**를 누르면 세 시트가 만들어진다.
  - `responses` : 1단계 판단 1행 = 사람 × 상황
  - `comparisons` : 2단계 비교 1행 = 사람 × 상황
  - `sessions` : 사람 1행 (성향 문항, 유형, 선택 분포 포함)
- 분석은 `responses`를 CSV로 내려받아 쓰면 된다.

## 4. 분석 계획 (사전등록용 요약)

- **주 가설** : 선례가 되는 상황에서, 사전에 위임을 택한 사람의 사후 거부 비율이
  평범한 조율 상황보다 높다.
- 모형 1 : 순서형 로지스틱 (종속=그냥 맡김/선 긋고 맡김/직접, 예측=선례성·표명성·가역성·관계),
  참가자와 시나리오에 랜덤 절편.
- 모형 2 : 사후 거부 여부에 대한 로지스틱, 사전 선택 × 상황 유형 상호작용.
- 모형 3 : 2단계 선택(hold/yield, closed/open)에 대한 로지스틱, 관계 성향과의 상호작용.
- 검정력 : `analysis/simulate_power.py` 참고. 가정한 효과 크기에서 N=80이면 95%.

## 윤리

이름·연락처는 수집하지 않습니다. 상대 에이전트 대화는 연구용으로 생성된 것이며
실제 상대와 주고받은 대화가 아닙니다. 참가자에게 종료 화면에서 이를 밝힙니다.
